## Escopo

Uma plataforma de gestão de operações de campo. Ela cobre autenticação,
workflows de negócio, persistência de dados e a geração de documentos Excel e
PDF.

## Arquitetura

O backend é feito em ASP.NET Core e guarda os dados no PostgreSQL; o front end
é feito em React e TypeScript.

## Qualidade e entrega

O código é coberto por testes unitários, de integração e end-to-end (E2E). O
projeto usa Docker e GitHub Actions.
