## Scope

A property management application. Its backend covers authentication and
authorisation, file storage and periodic jobs.

## Architecture

The backend is built with ASP.NET Core following Clean Architecture, and stores
its data in PostgreSQL.

## Quality and delivery

The code is covered by unit, integration and architecture tests. The project
uses Docker and CI/CD.
