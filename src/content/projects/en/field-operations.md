## Scope

A platform for managing field operations. It covers authentication, business
workflows, data persistence and the generation of Excel and PDF documents.

## Architecture

The backend is built with ASP.NET Core and stores its data in PostgreSQL; the
front end is built with React and TypeScript.

## Quality and delivery

The code is covered by unit, integration and end-to-end tests. The project
uses Docker and GitHub Actions.
